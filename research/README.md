# Forge-of-the-future research corpus

Overnight research (2026-10-12) on git forges, collaboration, CI and merge systems for heavily parallel agentic development.

- `0x-1x`, `2x-3x`: research reports, one per topic. Claims are tagged [read] (verified on an opened page), [secondary], or [inference].
- `4x`: independent forge designs from different angles.
- `5x`: red-team analyses of specific claims.
- `70-73`: full-coverage sweeps of the Anthropic and OpenAI blogs (every post Jan 2025–Oct 2026 listed, relevant ones read).
- `80-study-session-links-aidev.md` + `aidev-study/`: empirical study of session links in 71,677 agent PRs (raw data not committed; re-download from Hugging Face hao-li/AIDev).
- `81-pilot-semantic-conflicts.md` + `semconf/`: pilot replay of 143 concurrent agent PR pairs (A, B, A+B tests).
- `60-build-spec-landing-layer.md`: buildable spec for the landing layer on Cloudflare (Oct 14 entry).
- `sim/`: landing-throughput simulator (see 19-landing-throughput-model.md).
- `98-digest.md`: dense digest of the key numbers across reports.
- `99-my-priors.md`: priors written before research returned (kept for honesty about bias).

The synthesized report is published separately as a Claude Docs document.
